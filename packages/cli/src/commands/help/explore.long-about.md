Finds the projections that apply to this repository from the files it holds
(package manifests, database models, infrastructure, workflows, API surfaces and
more) and offers them as trial definitions, writing nothing. Run with --sweep to
try each candidate on recent changes, keep the useful ones with projections
adopt, show them in the viewer (projections view show), and add them to CI
(projections help agents ci). In VS Code, the Projections extension's Explore
view (Projections: Explore Repository) offers an alternate grid view.
